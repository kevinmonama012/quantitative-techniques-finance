# Applied Quantitative Finance & Statistical Techniques

Python implementation of foundational quantitative methods: descriptive statistics, normality testing, correlation & regression modeling, and hypothesis/A-B testing.

## Modules & Files

- descriptive_stats.py — Central tendency, dispersion, skewness, and kurtosis calculations.
- distributions_testing.py — Normality checks (Shapiro-Wilk, Kolmogorov-Smirnov) and distribution fitting.
- correlation_regression.py — Pearson/Spearman correlation matrices and linear regression diagnostics.
- b_test.py — Two-sample t-testing, p-value calculation, confidence intervals, and statistical power analysis.
- script.md — Technical explanations and practical applications.
